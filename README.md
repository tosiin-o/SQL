# SQL Data Analysis Project

## Overview

This project was completed as part of a **Level 3 Data Technician Bootcamp**, where I developed practical SQL skills by querying and analysing data from relational databases, including the **Northwind** and **World** datasets. The project focused on extracting insights, filtering data, combining tables, and producing meaningful reports using SQL.

## Key Skills Demonstrated

### SQL Query Fundamentals

Created and executed SQL queries using:

- `SELECT`
- `FROM`
- `WHERE`
- `ORDER BY`
- `DISTINCT`
- `AND`
- `OR`
- `IN`
- `BETWEEN`
- `LIKE`
- `LIMIT`

#### Examples
- Retrieved customer, product, and order information.
- Filtered records based on specific business requirements.
- Searched for records using conditional logic.
- Sorted datasets in ascending and descending order.
- Identified unique values using `DISTINCT`.
- Limited query results for reporting purposes.

### Data Filtering & Analysis

Applied filtering techniques to answer real-world business questions, including:

- Products priced above specific thresholds.
- Customers located in selected countries or cities.
- Orders placed within defined date ranges.
- Cities with populations within target ranges.
- Records matching text patterns using `LIKE`.

### SQL Joins

Worked with relational databases by combining data across multiple tables using:

- `INNER JOIN`
- `LEFT JOIN`

Developed an understanding of:
- `RIGHT JOIN`
- `FULL JOIN`
- `CROSS JOIN`

#### Join Applications
- Linked products with suppliers.
- Connected products to categories.
- Combined customer and order information.
- Created multi-table business reports.
- Retrieved related records using foreign key relationships.

### Aggregation & Grouping

Used aggregate functions to summarise data:

- `COUNT()`
- `AVG()`

Combined aggregates with:
- `GROUP BY`
- `ORDER BY`

Examples included:
- Counting products within categories.
- Calculating average city populations by country.
- Analysing frequency of city names.
- Producing summary reports for business stakeholders.

### Relational Database Concepts

Applied key database principles including:

- Primary Keys
- Foreign Keys
- One-to-Many Relationships
- Database Normalisation
- Relational Database Design

Designed a relational database model to manage:
- Learners
- Courses
- Instructors
- Enrolments

## Project Outcomes

Through SQL querying and database analysis, I was able to:

- Retrieve and analyse large datasets efficiently.
- Create meaningful reports from business data.
- Combine data from multiple tables using joins.
- Identify trends, patterns, and key insights.
- Apply relational database concepts to real-world scenarios.
